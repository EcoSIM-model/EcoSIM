Crop phenology: a node clock from planting to maturity

How EcoSIM moves an annual crop through emergence, floral initiation, anthesis, grain fill and physiological maturity, which traits set the timing, and what each stage changes in growth and yield formation.

Stages are dated by counting nodes, not degree-days

EcoSIM has no growing-degree-day sums for crops. Each live branch carries a real-valued node number that grows every hour at a temperature-dependent rate. A stage is reached when the node number passes a threshold expressed as a multiple of the maturity group. The model then writes the day of year into a per-branch calendar, iPlantCalendar_brch(stage, NB, NZ). A zero entry means the stage has not happened yet.

Three things sit outside the node clock: planting and harvest dates come from management input, emergence is a structural test on the seedling, and physiological maturity is declared when grain filling has stopped for a week.

What counts as a crop here. An annual (ISTYP = 0) whose seasonal type is evergreen (IWTYP = 0). The code comment in InitiateBranchFloral states that human-seeded annuals are set as evergreen; the season is bounded by planting and harvest instead of leaf-out and leaf-off rules. With this setting, stages 3 to 9 depend only on the node clock.

The eleven calendar entries

Indices are defined in ElmIDMod.F90:130–140. The history variable Growth_Stage_pft reports the same 0–10 integer.

The clock: hourly node initiation and leaf appearance

Once the main branch has emerged, UpdateBranchNodeNumber adds to two counters each hour:

nodes += XRNI · f(T) · stress leaves += XRLA · f(T) · stress

XRNI and XRLA are the rates at 25 °C in h⁻¹. Nodes drive the stage thresholds. Leaves decide which leaf is expanding and, as shown below, gate anthesis.

Temperature function

T' = T_canopy_growth + 2.667 · (2.5 − ZTYPI) [K] f(T) = exp(24.269 − 60000 / (R·T')) / (1 + exp((LG_ELOW − 710·T') / (R·T')) + exp((710·T' − LG_EHIGH) / (R·T')))

This is an Arrhenius response with low- and high-temperature inactivation. It equals 1 at 25 °C for a PFT with thermal zone 2.5, and uses the phenology-specific energies LG_ELOW and LG_EHIGH from the trait file. A cooler zone number shifts the whole curve toward lower temperatures.

Floral initiation has three gates and one bypass

Normal route

  1. Node competence. Node number exceeds GROUPX on the main branch. Each later branch of an annual needs one node fewer than the branch before it.
  2. Season started. Either the branch has logged VRNLI hours of lengthening days, or it is the planting year, on or after the planting day, with days lengthening.
  3. Photoperiod. With PPD = max(0, XDL − daylength):
    • day-neutral: always passes;
    • short-day: passes when days are shortening and PPD > XPPD;
    • long-day: passes when PPD < XPPD.

Bypass on shortening days

If the plant is an annual with evergreen seasonal type, its canopy is at least as tall as the snowpack, and today's daylength is shorter than yesterday's, floral initiation is set that day. Node competence and the photoperiod threshold are both skipped.

For a spring-sown crop that has not yet initiated, this pins floral initiation to the first day after the summer solstice. The same logic exists in the original ECOSYS hfunc.f; see the local note ecosys_ecosim_soybean_floral_gate_comparison_20261116.md.

On the day of floral initiation the model stores the node number. For a determinate annual this also becomes the final leaf number. For an indeterminate annual the leaf cap is set later, at stage 4, so leaves keep being added between stages 2 and 4.

Two consequences to check in a crop run.

1. Before floral initiation all shoot growth goes to leaf (72.5%) and petiole or sheath (27.5%), with nothing to stalk. A crop that waits for the solstice bypass therefore has no stalk growth until late June in the northern hemisphere, whatever its node number.

2. The bypass tests only for shortening days. A fall-sown annual configured as evergreen would initiate on its first hour of phenology after emergence. I did not check how the winter-crop PFTs in the parameter file are classed; if one uses IWTYP = 0, its floral date deserves a look.

Code: InitiateBranchFloral, threshold in CheckBranchNodeState.

The numbers come from the normalized counter (nodes − nodes at stage) / G compared against 0.25, 0.5 and 1.0 times 2.0 for the vegetative stages, and 0.5, 1.0 and 1.5 times 0.667 for the reproductive stages.

Stages are tested in an ELSE IF chain, one per hour, so anthesis is only tested after heading. Anthesis therefore falls at the later of two times: heading, or the hour when leaf appearance catches up with the floral node number. With XRLA close to XRNI, heading is the later one and anthesis follows it by an hour.

For annual drought-deciduous plants and for perennials there are extra leaf-off shortcuts through stages 3 to 7. They do not apply to an annual evergreen crop.

Branching

An annual adds shoot branches (tillers) only before floral initiation of the main branch, when root turgor is adequate and canopy non-structural C exceeds PB. The check runs once a day.

Code: partitioning, seed sites, seed set and grain fill, root_shoot_branching.

Maturity and the end of the season

Stage 10 is not a node threshold. Once seed number is set, the model counts consecutive hours in which reserve-to-grain transfer is effectively zero. At 168 hours it writes the maturity date. Grain filling can stop because the sink is full, because reserves are exhausted, or because grain N or P falls below the minimum ratio.

The automatic termination that follows maturity applies to annuals whose seasonal type is not evergreen. An annual evergreen crop stays active after stage 10 until the harvest date in the management input makes the PFT inactive.

Code: GrainFillOnBranch, set_plant_flags.

In a climate-change run (ICLM = 2) the maturity group is shifted by 0.30 per degree of imposed warming, so stage spacing changes with the scenario.

Points where labels and behavior differ

GROUPX is a total, not an increment. The trait description prints it as node number “on top of XTLI”. The code sets G = GROUPX − XTLI and tests nodes > G + XTLI, which is nodes > GROUPX. The label and the equation disagree; the equation is what runs.

Stage names are cereal names. Jointing, elongation and heading are node-count milestones applied to every crop. For soybean they are best read as fractions of the interval between floral initiation and flowering, not as observable events.

The soybean file opened here is long-day. Ne2_z014_spin33_2013-2023.plant_trait.desc.2016 lists IPTYP = Long day, XDL = 15.56 h and XPPD = 0.25 h. Under the long-day rule the photoperiod gate opens only when daylength exceeds 15.31 h. Soybean is a short-day plant, and the floral-gate note of 16 November assumed IPTYP = 1. One of the two does not describe this run.

Water stress barely moves the clock. The exponent 0.025 per MPa means drought changes stage dates by a few percent at most. Drought effects on a simulated crop come through growth and seed set, not through development rate.
