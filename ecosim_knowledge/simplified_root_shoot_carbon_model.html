EcoSIM • Reduced model proposal

Four biomass pools, with carbon allocation governed by transport and root function

Use fine-root, medium-root, coarse-root, and shoot carbon as the four dynamic states. GPP supplies carbon; transport connects shoots to roots; competing root sinks determine the relative allocation belowground.

Reserve extension, October 23: the six-state model with shoot and root reserves replaces the fast mobile-carbon closure below and analyzes conditions for coordinated shoot–root growth. This page retains the original four-state proposal for comparison.

2. States, units, and the four-state closure

SymbolDefinitionUnits

All biomass is carbon mass, not dry mass. Convert EcoSIM population/grid-cell totals to the same ground-area basis before fitting parameters. Here C is a pool name; “carbon” is the chemical element throughout.

Closure: mobile carbon equilibrates rapidly relative to biomass change. Its concentrations are algebraic variables, not integrated states. This preserves exactly four dynamic states, but removes delayed reserve accumulation and depletion. Biomass refers to structural carbon; transient nonstructural carbon storage is neglected.

The coarse pool includes the unresolved primary extension zone because EcoSIM has a separate primary-tip sink that a four-pool description otherwise cannot represent. This is a functional framework pool, not a strict diameter-only class. Do not introduce automatic F → M → C transfers: the source represents branching and thickening of distinct axes, and does not justify that universal maturation chain.

3. Relative allocation among root groups

3.1 Diagnose transport capacity from biomass

Choose a positive reference biomass B₀ and positive dimensionless conductance coefficients bᵢ. Linear biomass–conductance relations are the simplest closure; geometry and sapwood saturation are omitted.

g꜀ = b꜀ C/B₀ gₘ = bₘ M/B₀ (existing medium transport) gꜰ = bꜰ F/B₀ gₘ* = bₘ (M + ε C)/B₀ (medium growth/establishment only) H(a,b) = ab/(a+b) H₃(a,b,c) = abc/(ab+ac+bc)

Define H and H₃ as zero if any required input is zero. They represent series conductances. The establishment coefficient ε ≥ 0 supplies no carbon and creates no biomass directly; it only permits medium allocation when M = 0, C > 0, and F > 0.

3.2 Replace unresolved maturity and cytokinin with explicit proxies

a = C/(Kₐ + C) χ = χmax a F/(Kχ + F) with 0 ≤ χmax < 1 φ = gₘ/(g꜀ + gₘ) (zero when both are zero)

Kₐ and Kχ are positive carbon biomass scales; a and χ are dimensionless. The maturity proxy a replaces EcoSIM’s age, depth, and distance-behind-tip tests. χ represents a fine-root-associated thickening signal. EcoSIM actually diagnoses cytokinin from production, transport, and decay, and func_cyto includes high-concentration inhibition. This monotonic biomass proxy deliberately omits those dynamics and inhibition; it needs calibration.

3.3 Construct and normalize the sinks

wꜰ = (1 − χ) H(g꜀, (1 − φ)gꜰ + H(gₘ, φ gꜰ)) wₘ = a H₃(g꜀, gₘ*, gꜰ) w꜀ = g꜀ (e + χ) W = wꜰ + wₘ + w꜀ pꜰ = wꜰ/W, pₘ = wₘ/W, p꜀ = w꜀/W when W > 0

e > 0 is a dimensionless primary-extension weight. For W = 0, set all pᵢ = 0 and root growth capacity to zero. The direct and medium-mediated fine-root pathways partition gꜰ using φ, avoiding duplication of the same fine capacity. This is a reduced analogue of the source’s length-weighted pathways, not its exact geometry.

  • F = 0: both wꜰ and wₘ vanish. Existing medium roots retain their maintenance cost.
  • M = 0: fine roots still have a direct primary pathway; medium roots may establish through ε when living fine roots and primary framework exist.
  • C = 0: the root network has no primary support, so all root sinks vanish. Initialize with C > 0 and F > 0 for an established plant. Germination/re-establishment is outside this reduction.
  • Increasing χ: shifts sink strength toward coarse thickening and away from fine growth. Medium growth retains its separate series-conductance gate.

Define substrate-use capacities, all in g C m⁻² day⁻¹:

Aₛ = vₛ S Aᵣ = vᵣ B₀ W Aᵢ = pᵢ Aᵣ for i ∈ {F,M,C}

vₛ and vᵣ have units day⁻¹. The A values multiply the dimensionless mobile-carbon concentrations introduced below. They are uptake coefficients, not hard maximum fluxes.

4. Root–shoot carbon transfer without another state

4.1 Pay maintenance and define substrate inputs

Rₘ = mₛ S + mꜰ F + mₘ M + m꜀ C P = max(G − Rₘ, 0) D = max(Rₘ − G, 0) Dᵢ = D mᵢ Bᵢ/Rₘ if Rₘ > 0; otherwise 0 Lᵢ = τᵢ Bᵢ for Bᵢ ∈ {S,F,M,C}

mᵢ and τᵢ are maintenance and turnover rates, day⁻¹. Dᵢ represents structural carbon catabolized to pay a maintenance deficit. This whole-plant maintenance priority is a simplification of EcoSIM’s local reserve and remobilization rules. P is carbon available for growth before growth respiration; it is not NPP.

Optionally recycle a fraction ρᵢ of turnover into mobile substrate:

Hₛ = ρₛ Lₛ Hᵣ = ρꜰ Lꜰ + ρₘ Lₘ + ρ꜀ L꜀ Qₛ = P + Hₛ, Qᵣ = Hᵣ

Default: ρᵢ = 0. A positive ρ is an optional lumped carbon-remobilization assumption, not a measured EcoSIM resorption fraction. It returns carbon already removed through Lᵢ and therefore does not create carbon. It must not also be subtracted as litter.

4.2 Use EcoSIM’s concentration-gradient form

Let Vₛ = fₛS and Vᵣ = fꜰF + fₘM + f꜀C be effective active-carbon capacities in g C m⁻², with fixed fractions 0 < fᵢ ≤ 1. qₛ and qᵣ are dimensionless mobile C per active C. No V or q is an additional dynamic state.

K = k VₛVᵣ/(Vₛ + Vᵣ) (zero if either V is zero) J = K(qₛ − qᵣ)

k is day⁻¹ and K is g C m⁻² day⁻¹. This follows directly from the source’s exchange expression by substituting mobile masses Nₛ = qₛVₛ and Nᵣ = qᵣVᵣ. It is not a gradient of total structural biomass. J > 0 means shoot → root.

4.3 Eliminate the fast mobile pools algebraically

0 = Qₛ − Aₛqₛ − J 0 = Qᵣ + J − Aᵣqᵣ Δ = AₛAᵣ + K(Aₛ + Aᵣ) qₛ = [(Aᵣ + K)Qₛ + KQᵣ]/Δ qᵣ = [KQₛ + (Aₛ + K)Qᵣ]/Δ J = K(AᵣQₛ − AₛQᵣ)/Δ Uₛ = Aₛqₛ Uꜰ = pꜰ Aᵣqᵣ, Uₘ = pₘ Aᵣqᵣ, U꜀ = p꜀ Aᵣqᵣ

Uᵢ are gross substrate consumption fluxes before growth respiration. For nonnegative inputs and Δ > 0, all Uᵢ are nonnegative, Uₛ + Uꜰ + Uₘ + U꜀ = P + Hₛ + Hᵣ, and −Qᵣ ≤ J ≤ Qₛ. Thus the steady-state transfer cannot exceed available source carbon.

Direction and allocation: with no recycling, J is forward and the whole-plant fraction allocated to root substrate is J/P = KAᵣ/Δ. At large K it approaches Aᵣ/(Aₛ + Aᵣ); at small K it approaches zero. Reverse transfer requires a root-side mobile source: J < 0 when AₛQᵣ > AᵣQₛ. With ρ = 0 and no reserve state, nighttime reverse reserve export is unavailable.

J describes growth-substrate exchange after the whole-plant maintenance bookkeeping. Root maintenance transport is not resolved. For carbon-sufficient conditions without recycling, an approximate total shoot → root delivery is J plus root maintenance Rₘ,root. The simplified J should therefore not be compared directly with EcoSIM’s total nonstructural exchange diagnostic.

Degenerate cases: if Δ = 0, solve disconnected compartments separately: Uₛ = Qₛ when Aₛ > 0 and Uᵣ = Qᵣ when Aᵣ > 0. An isolated compartment with a positive input and zero use capacity has no quasi-steady solution; flag that condition rather than discarding the input. A living S > 0 with positive vₛ avoids this issue in the default, no-recycling model.

5. The four state equations and carbon balance

Let 0 < Yᵢ ≤ 1 be structural growth yields in g structural C per g substrate C consumed. The retained fraction becomes biomass and the rest is growth respiration.

dF/dt = Yꜰ Uꜰ − τꜰ F − Dꜰ dM/dt = Yₘ Uₘ − τₘ M − Dₘ dC/dt = Y꜀ U꜀ − τ꜀ C − D꜀ dS/dt = Yₛ Uₛ − τₛ S − Dₛ R𝗀 = Σᵢ (1 − Yᵢ)Uᵢ Lout = Σᵢ (1 − ρᵢ)τᵢBᵢ d(S + F + M + C)/dt = G − Rₘ − R𝗀 − Lout

This is the required closed plant-carbon budget. Internal J cancels between shoots and roots; recycled turnover cancels between loss and resupply. The only external source is GPP. External losses are maintenance respiration, growth respiration, and unrecycled turnover leaving the plant boundary. Soil/litter carbon is outside the four states.

With a common root yield, relative root biomass production equals pꜰ:pₘ:p꜀. With different yields, relative biomass production is Yꜰpꜰ:Yₘpₘ:Y꜀p꜀. Distinguish allocation of substrate carbon from allocation of structural growth.

A minimal implementation sequence

  1. Read nonnegative GPP and the four nonnegative biomass states. Evaluate conductances, maturity, thickening signal, and root sink weights.
  2. Compute maintenance, P, Dᵢ, turnover, and any explicitly enabled recycling.
  3. Compute active capacities, K, the algebraic concentrations, J, and Uᵢ.
  4. Evaluate the four derivatives and integrate with adaptive substeps. Check the integrated external carbon budget at every accepted step.
  5. Reject/substep a step that would make a pool negative. Do not clip negative biomass after the update: that adds unaccounted carbon. If using donor-limited fluxes, adjust all matching respiration, turnover, and recycling terms consistently.

There are no direct transfers of structural fine-root carbon into medium or coarse pools. The coupling occurs through transport, sink competition, and optional explicitly budgeted remobilization.

6. Worked allocation and conservation check

Illustrative numbers only; these are not EcoSIM defaults or fitted plant traits. Suppose the biomass-dependent rules at one instant give Aₛ = 4, Aᵣ = 6, K = 3, and (pꜰ,pₘ,p꜀) = (0.5,0.2,0.3). The A and K units are g C m⁻² day⁻¹. Let G = 12, Rₘ = 2, all Y = 0.75, total turnover = 1, and all ρ = 0.

P = 10; Δ = 4×6 + 3×(4+6) = 54 qₛ = 90/54 = 1.666667; qᵣ = 30/54 = 0.555556 J = 3×(1.666667 − 0.555556) = 3.333333 Uₛ = 6.666667 (Uꜰ,Uₘ,U꜀) = (1.666667, 0.666667, 1.000000) Root structural production = 0.75×3.333333 = 2.500000 R𝗀 = 0.25×10 = 2.500000 Total biomass change = 12 − 2 − 2.5 − 1 = 6.500000

The q values are effective algebraic concentrations in this linear model, not bounded reserve fractions. If comparison with EcoSIM implies excessive nonstructural carbon, the fast-pool closure is invalid; adjusting rates or adding reserve dynamics is necessary.

For a reversal example with the same capacities, set P = Hₛ = 0 and Hᵣ = 2 through explicitly budgeted root remobilization. Then J = −24/54 = −0.444444: roots supply shoots, Uₛ = 0.444444, and total root substrate use is 1.555556. Their sum is the remobilized 2, not new carbon.

7. Parameters, calibration, and limits

Parameter groupRole and constraints
B₀; bꜰ,bₘ,b꜀Reference carbon biomass and relative transport effectiveness; B₀ > 0, all b > 0. Fix B₀ by convention; biomass data alone may not identify each b separately.
ε, e, Kₐ, Kχ, χmaxMedium establishment; primary extension; maturity and fine-root signal scales; maximal thickening signal. ε ≥ 0, e > 0, both K scales > 0, 0 ≤ χmax < 1.
vₛ,vᵣ,k; active fractions fᵢSubstrate-use coefficients and exchange; all rates positive in day⁻¹, 0 < fᵢ ≤ 1. Shoot active fraction substitutes for the source’s explicit leaf/sheath pool.
mᵢ,τᵢ,Yᵢ,ρᵢMaintenance, turnover, growth yield, and optional recycling. mᵢ,τᵢ ≥ 0; 0 < Yᵢ ≤ 1; 0 ≤ ρᵢ ≤ 1, with ρᵢ = 0 initially.

Start with a common root yield, constant active fractions, no recycling, and fixed B₀. Fit turnover and respiration from independent evidence before tuning allocation. Prefer fitting to EcoSIM trajectories of the four aggregated carbon pools, root-group growth, maintenance, and growth respiration together. Compare fractions and fluxes on the same time and area basis.

Typical fine-root turnover may exceed medium- and coarse-root turnover, but impose this ordering only when supported for the plant and conditions. No universal fine:medium:coarse biomass ratio follows from the source: ratios emerge from allocation, yields, turnover, and environmental constraints.

What four states cannot retain: explicit reserve memory, branch structure, root age/depth distributions, changing conductive sapwood fraction, hydraulic/hormonal feedbacks, or N/P stoichiometry. Water, oxygen, and nutrients are assumed nonlimiting in the minimal model. If needed, prescribe environmental multipliers on growth capacities and separate modifiers on maintenance; setting a growth weight to zero must not erase maintenance. Mechanistic N/P conservation requires additional states.

Because GPP is prescribed, shoot and root biomass do not feed back onto photosynthesis here. GPP must already reflect those constraints externally. Constant forcing applied to a dead or severely depleted plant is outside the valid domain. Use positive established-plant initial conditions; this document does not define seed carbon or establishment reserves.
